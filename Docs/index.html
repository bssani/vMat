V-Mat 사용법Guide

레벨에서 고른 메쉬에 preset으로 모아 둔 material을 클릭 한 번으로 입히는 언리얼 에디터 플러그인입니다. 순서대로 따라 하면 됩니다.

An Unreal Editor plugin that applies materials from a preset to the meshes you select in the level, in one click. Follow the steps in order.

작성자 최필립 · GMTCK CX Team

Author Philip Choi · GMTCK CX Team

  • Unreal Engine 5.5
  • 에디터 전용
  • Editor only
  • Win64
  • v0.1.0

먼저 알아두세요. V-Mat은 액터 하나가 아니라 원본 StaticMesh 에셋의 material을 바꿉니다. 그래서 같은 메쉬를 쓰는 다른 액터도 함께 바뀝니다.

Before you start. V-Mat changes the material on the source StaticMesh asset, not on a single actor. Every other actor that uses the same mesh changes too.

시작하기Getting started

설치하고 열기

Install and open

1

Plugins 폴더에 V-Mat 넣기

Put V-Mat in the Plugins folder

프로젝트 폴더 안의 Plugins 폴더에 VMat 폴더를 통째로 넣습니다. Plugins 폴더가 없으면 새로 만듭니다.

프로젝트를 열면 V-Mat이 자동으로 켜집니다.

git으로 받았다면 Binaries 폴더가 없어서, 처음 열 때 다시 빌드할지 묻는 창이 뜹니다. Yes를 누르면 됩니다. 빌드하려면 Visual Studio(C++)가 설치돼 있어야 합니다.

Copy the whole VMat folder into the Plugins folder of your project. Create Plugins if it doesn't exist.

V-Mat turns on by itself when you open the project.

If you got the plugin from git, it has no Binaries folder, so Unreal asks to rebuild it the first time. Click Yes. Building needs Visual Studio with C++.

2

V-Mat 창 열기

Open the V-Mat window

레벨 에디터 위쪽 툴바에서 Platforms 오른쪽에 있는 V-Mat 버튼을 누릅니다.

메뉴 Tools → V-Mat으로도 열 수 있습니다.

In the level editor toolbar, click V-Mat, to the right of Platforms.

You can also use Tools → V-Mat in the menu bar.

3

창 구성 보기

Know the window

맨 위 두 탭으로 화면을 바꿉니다.

  • Palette: 선택한 메쉬에 material을 입힙니다. 대부분은 이 탭을 씁니다.
  • Multi-slot: material slot이 2개 이상인 메쉬를 찾아서 slot별로 입힙니다.

맨 아래 줄에는 지금 선택한 액터 수와 바뀔 메쉬 수가 나옵니다.

Switch views with the two tabs at the top.

  • Palette: applies materials to the selected meshes. You'll use this tab most of the time.
  • Multi-slot: finds meshes with two or more material slots and sets each slot separately.

The bottom line shows how many actors are selected and how many meshes will change.

Palette

Material 모으고 입히기

Collect and apply materials

preset에 material을 모아 두고, 레벨에서 메쉬를 고른 다음 material을 누릅니다.

Collect materials in a preset, select meshes in the level, then click a material.

4

Material 추가하기

Add materials

콘텐츠 브라우저에서 material을 고르고 Add selected를 누릅니다.

  • 여러 개를 한 번에 골라도 됩니다. material instance도 됩니다.
  • 이미 들어 있는 material은 다시 추가되지 않습니다.

Select materials in the Content Browser, then click Add selected.

  • You can select several at once. Material instances work too.
  • Materials already in the preset aren't added twice.
5

끌어다 놓아서 추가하기

Or drag and drop

콘텐츠 브라우저에서 material을 V-Mat 창 가운데로 끌어다 놓아도 추가됩니다. 여러 개를 한 번에 끌어도 됩니다. 놓을 수 있는 곳은 파랗게 바뀝니다.

You can also drag materials from the Content Browser into the middle of the V-Mat window. Dragging several at once works. The drop area turns blue.

6

Preset 만들고 관리하기

Create and manage presets

preset은 material 묶음입니다. 처음에는 Default만 있습니다. 내장, 외장처럼 쓰임새별로 만들어 두면 고르기 편합니다.

드롭다운에서 preset을 고르고, 오른쪽 아이콘으로 관리합니다.

A preset is a set of materials. You start with Default. Making presets per use, such as Interior and Exterior, keeps the list short.

Pick a preset from the dropdown and manage it with the icons on the right.

이름 바꾸기 (Enter 확정, Esc 취소)Rename (Enter to confirm, Esc to cancel)
새 preset 만들기New preset
지금 preset 복사Duplicate this preset
지금 preset 삭제 (확인 창이 뜹니다)Delete this preset (asks first)

바꾸는 즉시 저장됩니다. 저장 버튼은 없습니다. 드롭다운 목록 오른쪽 숫자는 그 preset에 든 material 수입니다.

Changes save right away; there's no save button. The number next to each preset in the list is how many materials it holds.

7

메쉬에 material 입히기

Apply a material to meshes

  1. 레벨에서 메쉬 액터를 선택합니다. 여러 개를 골라도 됩니다.
  2. V-Mat 맨 아래 줄에서 바뀔 메쉬 수를 확인합니다.
  3. material 타일을 누릅니다.
  1. Select mesh actors in the level. You can select several.
  2. Check the bottom line of V-Mat for how many meshes will change.
  3. Click a material tile.
누르기 전에 꼭 확인하세요
  • 같은 메쉬를 쓰는 다른 액터도 같이 바뀝니다. 볼트 하나만 골라도 같은 볼트 메쉬는 전부 바뀝니다. 알림에 함께 바뀐 액터 수가 나옵니다.
  • 바뀐 메쉬 에셋은 바로 저장됩니다. 레벨은 평소처럼 Ctrl+S로 저장합니다.
  • 되돌리려면 Ctrl+Z를 한 번 누릅니다. 되돌린 뒤에는 메쉬를 다시 저장해야 합니다.
  • 이런 메쉬는 건너뜁니다. 건너뛴 내용은 아래 줄에 노란 경고로 나옵니다.
    • slot이 2개 이상인 메쉬: 경고 옆 Show multi-slot을 누르면 Multi-slot 탭에서 바로 이어서 할 수 있습니다.
    • 엔진이나 다른 플러그인 메쉬(/Game 밖)
    • 메쉬가 없는 액터(라이트 등)
Check before you click
  • Other actors that use the same mesh change too. Select one bolt and every actor using that bolt mesh changes. The notification tells you how many actors changed.
  • Changed mesh assets are saved right away. Save the level as usual with Ctrl+S.
  • Press Ctrl+Z once to undo the whole click. Save the meshes again after undoing.
  • These are skipped, and a yellow warning on the bottom line says so:
    • Meshes with two or more slots. Click Show multi-slot next to the warning to continue in the Multi-slot tab.
    • Engine or other plugin meshes (outside /Game)
    • Actors without a mesh, such as lights
타일 다루기
  • 타일에 마우스를 올리면 오른쪽 위에 ×가 보입니다. 누르면 preset에서 빠집니다. material 에셋은 지워지지 않습니다.
  • 타일을 우클릭하면 입히기, 콘텐츠 브라우저에서 보기, preset에서 빼기 메뉴가 나옵니다.
  • material을 옮기거나 지워서 찾을 수 없으면 타일에 Missing이 뜹니다.
Working with tiles
  • Hover a tile to show × in its corner. It removes the material from the preset; the asset itself stays.
  • Right-click a tile to apply it, show it in the Content Browser, or remove it from the preset.
  • A tile shows Missing when its material was moved or deleted.
Multi-slot

Slot이 여러 개인 메쉬

Meshes with several slots

Palette는 slot이 2개 이상인 메쉬를 건너뜁니다. 이런 메쉬는 이 탭에서 slot을 골라 따로 입힙니다.

Palette skips meshes with two or more slots. Use this tab to pick a slot and set it on its own.

8

레벨에서 찾기

Find them in the level

Multi-slot 탭을 처음 열면 지금 레벨을 훑어서 slot이 2개 이상인 메쉬를 목록으로 보여줍니다. 탭 이름 옆 숫자가 찾은 개수입니다.

  • 레벨을 바꾸거나 액터를 추가했으면 Scan level을 다시 누릅니다.
  • 위쪽 줄에 훑은 메쉬와 액터 수, 걸린 시간이 나옵니다. 이미 레벨에 올라온 메쉬만 확인해서 금방 끝납니다.
  • 검색칸에 메쉬 이름이나 폴더 일부를 쓰면 걸러집니다. 열 제목을 누르면 정렬됩니다.
  • /Game 안의 메쉬만 나옵니다. World Partition 레벨은 지금 로드된 액터만 훑습니다.

The first time you open the Multi-slot tab, it scans the open level and lists meshes with two or more slots. The number on the tab is how many it found.

  • After changing levels or adding actors, click Scan level again.
  • The status line shows how many meshes and actors were checked and how long it took. It only looks at meshes already loaded in the level, so it's quick.
  • Type part of a mesh name or folder in the search box to filter. Click a column header to sort.
  • Only meshes under /Game are listed. In World Partition levels, only loaded actors are scanned.
9

Slot에 material 넣기

Set a material on a slot

  1. 목록에서 메쉬를 고릅니다.
  2. 아래 Slots에 그 메쉬의 slot과 지금 들어 있는 material이 나옵니다. 바꿀 slot을 고릅니다. Ctrl/Shift로 여러 개 골라도 됩니다.
  3. 맨 아래 material을 누르면 고른 slot에만 들어갑니다.
  • 맨 아래 material 줄은 Palette 탭과 같은 preset을 씁니다. 오른쪽 드롭다운으로 바꿀 수 있습니다.
  • slot을 고르지 않으면 material이 흐리게 나오고 눌리지 않습니다.
  • 저장과 Ctrl+Z는 Palette와 같습니다.
  • 목록 줄에 마우스를 올리면 slot별 material이 툴팁으로 나옵니다.
  1. Pick a mesh in the list.
  2. Slots below shows that mesh's slots and their current materials. Pick the slots to change. Use Ctrl/Shift for several.
  3. Click a material at the bottom. Only the picked slots change.
  • The bottom row uses the same presets as the Palette tab. Switch presets with the dropdown on its right.
  • With no slot picked, the materials are dimmed and can't be clicked.
  • Saving and Ctrl+Z work the same as in Palette.
  • Hover a row in the list to see each slot's material.
10

여러 메쉬를 한 번에 바꾸기

Change many meshes at once

CAD 데이터는 같은 부품이 _2, _3처럼 따로따로 메쉬로 들어오는 경우가 많습니다. 이럴 때는 한 번에 바꿉니다.

  1. 검색칸에 부품 이름 일부를 씁니다. 예: BOLT
  2. 목록을 한 번 클릭하고 Ctrl+A로 검색된 메쉬를 전부 고릅니다.
  3. Slots가 묶여서 나옵니다. 오른쪽에서 묶는 기준을 고릅니다.
    • By material: 지금 같은 material이 든 slot끼리 묶습니다.
    • By slot name: slot 이름이 같은 것끼리 묶습니다. Datasmith CAD로 가져온 메쉬는 CAD material ID가 slot 이름이 되어서, 원래 같은 재질이던 slot이 한 줄로 모입니다.
  4. 줄을 고르고 material을 누르면 고른 메쉬 전부에 들어갑니다.

메쉬 수백 개를 한 번에 바꾸면 몇 초 걸릴 수 있고, 오래 걸리면 진행 창이 뜹니다.

CAD data often brings the same part in as separate meshes named _2, _3 and so on. Change them together.

  1. Type part of the part name in the search box, for example BOLT.
  2. Click the list once, then press Ctrl+A to pick every mesh the search found.
  3. Slots now shows grouped rows. Choose how to group them on the right:
    • By material: slots that currently use the same material.
    • By slot name: slots with the same name. Datasmith CAD imports name slots after the CAD material ID, so slots that started as the same CAD material stay together.
  4. Pick a row and click a material. It goes into that slot on every picked mesh.

Changing hundreds of meshes can take a few seconds; a progress window appears if it does.

11

레벨에서 위치 찾기, 에셋 열기

Find in the level, open the asset

목록 아래 버튼은 고른 메쉬에 대해 동작합니다. 목록을 우클릭해도 같은 메뉴가 나옵니다.

  • Select in level: 그 메쉬를 쓰는 액터를 레벨에서 전부 선택하고 카메라를 그쪽으로 옮깁니다. 줄을 더블클릭해도 같습니다.
  • 폴더 아이콘: 콘텐츠 브라우저에서 메쉬 에셋을 보여줍니다.
  • 연필 아이콘: Static Mesh Editor로 엽니다. 한 번에 10개까지 열 수 있습니다.

The buttons under the list act on the picked meshes. Right-clicking the list shows the same options.

  • Select in level: selects every actor that uses the mesh and moves the camera to them. Double-clicking a row does the same.
  • Folder icon: shows the mesh asset in the Content Browser.
  • Pencil icon: opens the Static Mesh Editor, up to 10 meshes at a time.
Preset 공유Sharing presets

다른 프로젝트에서 같은 preset 쓰기

Use the same presets in another project

preset은 플러그인 폴더 안 Plugins/VMat/Config/VMatPresets.json에 저장됩니다.

  • VMat 폴더를 다른 프로젝트로 복사하면 preset도 같이 갑니다. git으로 받는 사람도 같은 preset을 받습니다.
  • material은 /Game/... 경로로 저장됩니다. 다른 프로젝트에도 같은 경로에 있으면 그대로 쓰이고, 없으면 타일에 Missing이 뜹니다.
  • 마지막에 쓰던 preset은 사람마다 따로 기억합니다(프로젝트 Saved 폴더). 공유 파일에는 들어가지 않습니다.
  • 예전 버전이 프로젝트 Config/DefaultEditor.ini에 저장한 preset은, 플러그인에 json이 없으면 처음 열 때 json으로 옮겨집니다.

Presets are saved inside the plugin folder, in Plugins/VMat/Config/VMatPresets.json.

  • Copy the VMat folder to another project and the presets come with it. People who get the plugin from git get the same presets.
  • Materials are stored by their /Game/... path. If the other project has them at the same path, they just work; otherwise the tile shows Missing.
  • The last preset you used is remembered per person (in the project's Saved folder) and isn't part of the shared file.
  • Presets that an older version saved in the project's Config/DefaultEditor.ini move into the json the first time V-Mat opens, if the plugin has no json yet.
